# Nordrive VTC — Application Web & Portail Chauffeurs

Site officiel et portail d'onboarding pour la flotte VTC **Nordrive** (Partenaire agréé Uber, Bolt, Heetch).

## 🚀 Fonctionnalités Clés
- **Hero & Landing Page** basée sur la DA officielle du flyer Nordrive (Ardoise titane & Or champagne).
- **Formulaire de Rattachement Express** : Inscription mobile en 15 secondes chrono (4 champs indispensables + accordéon documents).
- **Programme Ambassadeur Parrainage 200€** : Formulaire 4 champs + partage direct de l'invitation sur WhatsApp.
- **Simulateur de Gains en Ligne** : Comparatif interactif Auto-Entrepreneur vs Statut Salarié Flotte.
- **Formulaire de Contact & Devis Assurance VTC**.
- **Upload sécurisé des justificatifs** vers Cloudinary.

## 🛠️ Stack Technique
- React 18
- Vite
- TypeScript
- Tailwind CSS & Lucide Icons
- Déploiement : Vercel

## 📦 Installation & Lancement Local
```bash
# Installer les dépendances
npm install

# Lancer le serveur local
npm run dev

# Compiler pour la production
npm run build
```
